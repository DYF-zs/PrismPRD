# PDF 字体资源

- `NotoSansSC-Regular.ttf`：Google Fonts Noto Sans SC 的 400 字重静态实例。
- `NotoEmoji-Regular.ttf`：Google Fonts Noto Emoji 的 400 字重静态实例，导出使用黑白字形。
- 授权文本分别见同目录 `NotoSansSC-OFL.txt` 与 `NotoEmoji-OFL.txt`；字体遵循 SIL Open Font License 1.1。
- 官方来源、上游文件和生成文件 SHA-256、生成工具版本见 `manifest.json`。

字体作为 classpath 资源打包，PDF 导出时嵌入实际使用的字形。
